# whisper-gigaam — портативный голосовой клиент

Голосовой ввод для **удалённых машин**: микрофон → ваш сервер транскрибации → текст в активное окно (чат, редактор, мессенджер).

Клиент лёгкий: только `sounddevice` + `pynput`, никакого torch/GigaAM — распознавание идёт на сервере.

## Требования

- Windows 10/11 (x64);
- Python 3.10+ (`winget install --id Python.Python.3.12`); uv не нужен;
- сеть до сервера транскрибации (`ipconfig` на сервере → IPv4, по умолчанию порт 8010).

## Установка и запуск

1. Скопируйте папку `portable/` на удалённую машину.
2. Запустите **start_client.bat** (или `.\start_client.ps1`).
   При первом запуске автоматически создаётся `.venv`, ставятся 2 зависимости и открывается `client.env` — впишите адрес сервера:
   ```ini
   VOICE_URL=http://192.168.130.155:8010
   ```
3. Кликните в поле ввода → **Ctrl+Alt+Z** → говорите → **Ctrl+Alt+Z** → текст вставляется. Enter — отправить.

## Использование

```powershell
.\start_client.ps1 --list-devices          # список микрофонов
.\start_client.ps1 --device "USB Condenser"  # выбрать микрофон разово
.\start_client.ps1 --url http://10.0.0.5:8010   # другой сервер (без правки client.env)
.\start_client.ps1 --api openai            # через /v1/audio/transcriptions (OpenAI)
.\start_client.ps1 --file rec.wav --print-only   # проверка без микрофона
```

## Настройки (client.env)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `VOICE_URL` | `http://127.0.0.1:8010` | адрес сервера транскрибации |
| `VOICE_API` | `native` | `native` = `/transcribe`, `openai` = `/v1/audio/transcriptions` |
| `VOICE_DEVICE` | авто | микрофон: фрагмент имени или индекс из `--list-devices` |
| `VOICE_HOTKEY` | `<ctrl>+<alt>+z` | комбинация старт/стоп записи |
| `VOICE_PASTE` | `1` | `0` — только буфер обмена, без авто-вставки |
| `VOICE_SEND_ENTER` | `0` | `1` — сразу нажимать Enter после вставки |

Приоритет: аргументы командной строки → переменные окружения → `client.env`.

## Проверка связи с сервером

```powershell
curl.exe http://192.168.130.155:8010/health
```

Должен вернуться JSON с `model` и `device`. Если нет — проверьте, что сервер запущен, и разрешите Python в межсетевом экране Windows на машине сервера.

## Устранение проблем

| Симптом | Решение |
|---|---|
| «Не найден Python» | `winget install --id Python.Python.3.12`, новая консоль |
| «Ошибка: HTTP 404/Connection refused» | неверный `VOICE_URL` или сервер не запущен |
| «Микрофон не найден» | `--list-devices`, укажите `VOICE_DEVICE` |
| Текст не вставляется | вывод клиента печатает активное окно и статус SendInput; окна «от администратора» требуют запуска клиента от администратора |
| Запись есть, «Ничего не распознано» | проверьте выбранный микрофон (можно не тот) |
